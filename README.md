# 태극 타깃 (동작 목업)

타깃이 뜨면 맞는 높이로 친다. 아래=아래막기, 몸통=지르기, 얼굴=얼굴막기, 무릎=앞차기.
판정은 "맞는 신체 부위가 타깃에 닿았는가" 하나. 놓치면 조용히 사라진다.

- 실행: `태극 타깃 시작.command` 더블클릭 (또는 `python3 serve.py 8010` 후 http://localhost:8010)
- 카메라 켜기 → 카메라 앞 칸에 서면 참가 (4명까지, MediaPipe Pose 다인)
- 리모컨(프레젠터): ▶=시작/정지(PageDown·Space), ◀▶=코스(PageUp·화살표)
- 코스 4개: 막기 / 치기 / 차기 / 태극 1장(타깃 20개가 품새 순서·방향대로)
- 첫 화면에서 "카메라 켜기"를 누르면 시작. 카메라가 없으면 동작하지 않는다.
- 구령(V): 타깃이 뜰 때 기술 이름을 읽어 준다 (브라우저 한국어 음성)
